# Cerff

> Software & Infrastructure Analyst | Focused on Problem Solving & Automation

## Who am I?

I am a tech professional driven by a deep interest in understanding how systems operate underneath the hood — from core logic and algorithms to practical infrastructure setup and basic electronics. 

I believe that understanding the fundamentals grants us the necessary flexibility to quickly learn and master any tool. I follow the **KISS (Keep It Simple, Stupid)** principle: code and architecture should be so clean and efficient that they explain themselves.

## What I Do and Develop

* **Agnostic Approach:** I don't bind myself to a fixed framework or label. When faced with a complex issue, I dig into the root cause, research the best approach, and implement an efficient solution.
* **Infrastructure & Homelab:** Passionate about self-hosting. I build and maintain my own home laboratory environment, managing local virtualization setups, service deployments, and data storage solutions.
* **Linux & Systems:** Strong familiarity with Linux environments, focused on what actually matters: shell scripting, user/permission management, system automation, and virtualization utilizing Proxmox VE.
* **Practical Versatility:** Experienced with Robotic Process Automation (RPA), network configuration, systems troubleshooting, and hardware diagnosis/maintenance.

## 🚀 Featured Projects (Pinned Repositories)

Here are the key projects that represent my practical experience, problem-solving skills, and a bit of my journey:

* **Cerffy (Music Streaming App):** A personal streaming platform connected directly to a self-hosted Navidrome music server. Currently handling the backend logic, infrastructure integration, and music library synchronization.
* **AVL-Tree:** A pure implementation of an AVL Tree built after a university challenge where the professor claimed "no one would be able to code it" and jokingly promised a barbecue to whoever did. I built it, explained it line by line the next week, and I'm still waiting for that barbecue.
* **PelandDealsAutomator:** An RPA automation bot developed as a practical test for an RPA technical selection process, focusing on data extraction and task optimization.
* **Running for the History:** A digital game developed as a final capstone project (TCC), showcasing object-oriented programming, game loops, and resource optimization.
* **Dino Lab:** A horror game created under a strict deadline for a community game jam event (Toddyn's Game Jam).
* **SokolTriangle_CPP:** A foundational, low-level graphics script rendering a basic triangle utilizing the Vulkan API.

## Philosophy & Problem Solving

I don't look for quick, temporary fixes. When a problem arises, I am fully open to researching deeply, digging into documentation, and finding not just *a* solution, but the most **efficient and optimized way** to solve it. My goal is always to improve performance, facilitate system workflows, and automate repetitive tasks to streamline operations.
